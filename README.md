## Deployment
Upload/replace the five files in your existing GitHub repository. Commit once, then test your GitHub Pages site. If Netlify is still linked to `main`, the same commit may also trigger a chargeable Netlify production deploy; disconnect Netlify auto-deploy first if avoiding those credits is important.
